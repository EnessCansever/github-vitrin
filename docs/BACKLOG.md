# Backlog — v1 dışında

Bu liste uygulama yetkisi veya teslim taahhüdü değildir. Kaynak sözleşmede v1 dışında bırakılan maddeleri korur; kapsam değişikliği Enes'in açık kararı olmadan yapılmaz.

- Hesap sistemi ve cihazlar arası hesap geçmişi; profil sahipliği doğrulaması v1'de yok.
- Ödeme.
- Global sıralama, anonim profil dizini/listesi.
- AI sohbet veya AI tabanlı analiz; v1 kanıtlardan TR/EN şablonlar üretir.
- Otomatik GitHub yazma; analiz hesapta değişiklik yapmaz.
- Ayrıntılı kod kalitesi incelemesi.
- Üç renk teması; v1 tek tutarlı tema.
- Forklar ve organizasyon repolarının değerlendirilmesi; v1 kapsam dışı olmak yeterlilik yargısı değildir.
- Demo sitelerinin erişilebilirlik/çalışırlık taraması; v1 dış URL taraması yapmaz.
- “Kurs Arşivi” etiketi; eğitim projesi olduğu güvenilir biçimde belirlenemediği için v1'de kullanılmaz.

## İhtiyaç kanıtı olmadan eklenmeyecekler

Redux, mikroservis, Redis, kuyruk ve ek servisler somut ihtiyaç olmadan eklenmez. Bu liste bunların ileride gerekli olacağı varsayımı değildir. Yeni kapsam dışı fikirler burada kaydedilir; v1 görevlerine sessizce taşınmaz.
